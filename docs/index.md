# Metis

Metis is a multi-engine forecasting and thesis-building framework.

The public site is intentionally selective. It shows the framework, public
patterns, and sanitized progress reports, while private schema, raw evidence,
and active prediction details stay inside the working repository.

## Public Sections

- Core overview and operating principles
- Pattern library
- Portfolio-level engine status
- Selected weekly or monthly public reports

## Private Boundary

The public site is not the system of record. The private workspace remains the
source for raw ledgers, engine-specific schemas, source files, unresolved
prediction details, and human review notes.
