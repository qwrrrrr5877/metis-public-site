## Core Principles

<div class="metis-principles">
  <div>
    <strong>Watch objects can teach without becoming calibration samples.</strong>
    <p>Metis can learn from weak signals without pretending every useful observation deserved formal registration.</p>
  </div>
  <div>
    <strong>Engines own local context; Core owns shared discipline.</strong>
    <p>Domain engines keep their texture, while the core keeps progress, review, and transfer legible.</p>
  </div>
  <div>
    <strong>A correct narrow prediction can still miss the structure.</strong>
    <p>Postmortems ask what the event revealed beyond the object that was scored.</p>
  </div>
  <div>
    <strong>Private ledgers remain the memory.</strong>
    <p>The public site explains the method; raw evidence, unresolved objects, and schema details stay private.</p>
  </div>
</div>

## Operating Shape

Metis treats each domain as an engine with its own memory, evidence standards,
and review cadence. The shared core stays deliberately small: manifests,
weekly packets, compatibility logs, pattern promotion, and portfolio review.

  <div class="metis-panel">

## Public Boundary

The public site is intentionally selective. It shows the framework, public
patterns, and sanitized progress reports. The private workspace remains the
system of record for raw ledgers, evidence archives, source files, unresolved
prediction details, and human review notes.
