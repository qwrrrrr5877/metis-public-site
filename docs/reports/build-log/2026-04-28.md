## 1. Goal

Today established the first working Metis Core layer for coordinating multiple pre-existing Metis-class engines:

```text
IDN_NI
FOMC
ODAC
AI_CAP
```

The design choice was **not** to rebuild these engines. Instead, each legacy engine received a thin Metis facade:

```text
metis_manifest.yaml
weekly_packet.yaml
metis_compatibility_log.csv
legacy_boundary.md
```

The intended operating principle is:

```text
legacy artifacts are preserved;
future increments are governed.
```


Core change mechanism:


Added:

```text

patterns/candidate_registration_gate.md
patterns/source_placeholder_event_workflow.md
```

These are reusable workflow shapes, not domain rules.

Pattern boundary:

```text
Core may define workflow shape.
Engines keep local domain checks.
```

Examples:

```text
FOMC keeps voter linkage, meeting baseline, and active lesson recall local.
ODAC keeps clinical-statistical gate and precedent validity local.
AI_CAP keeps source archive validation and human-only probability application local.
IDN_NI keeps actor/institution and four-indicator execution checks local.
```

```text

promote lessons
write weekly_packet.yaml
```

```text

promote reusable patterns
```
